# 🎵 Spotify Clone – Music Streaming UI

A frontend recreation of Spotify's music streaming interface, built using HTML5 and CSS3. This project focuses on creating a clean, visually appealing music browsing experience inspired by Spotify.

## 📌 About the Project

Spotify Clone is a frontend web development project created to practice and demonstrate HTML and CSS skills.

The project recreates the visual layout of a music streaming platform, focusing on page structure, styling, layout design and user interface elements.

## ✨ Features

- Spotify-inspired user interface.
- Clean and modern design.
- Sidebar navigation layout.
- Music browsing sections.
- Playlist and album display layouts.
- Custom styling using CSS.
- Structured web pages using HTML.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Web page structure |
| CSS3 | Styling and layout design |

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/SheetalDandge/Spotify-Clone.git
```

### 2. Navigate to the Project Folder

```bash
cd Spotify-Clone
```

### 3. Run the Project

Open `index.html` in your browser.

You can also open the project using the VS Code Live Server extension.
